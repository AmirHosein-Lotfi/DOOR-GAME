# دور

بازی موبایل تحت وب، تیم‌های دونفره، pass-and-play روی یک گوشی.

## توسعه محلی

```bash
npm install
npm run dev
```

## دیپلوی روی Cloudflare Workers

```bash
npm run deploy
```

یا از داشبورد Cloudflare، این ریپو رو با Workers Builds کانکت کن — build command: `npm run build`, output: `dist`.
